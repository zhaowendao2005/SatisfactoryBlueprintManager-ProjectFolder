
# SatisfactoryBlueprintManager

> 一个强大的《幸福工厂》(Satisfactory) 蓝图管理工具，让您的蓝图管理更轻松、更高效！

## 📖 简介

你是否因为游戏中加载大量的蓝图导致性能损失？你是否苦恼于游戏中难用的分类系统以及无法存档的迁移蓝图配置？你是否缺少一个在不打开游戏就查看蓝图的方案？

**SatisfactoryBlueprintManager (SBM)** 为您提供一个完整的工具箱来解决这些烦恼！

## ✨ 核心功能

### 🗂️ 功能一：管理你的蓝图库

综合管理你的蓝图库，告别因下载大量蓝图而无法有效管理的困扰！

- **自动检测**：程序会自动检测您存档文件夹的蓝图文件夹位置，实现无缝联动
- **可视化交互**：提供直观的可视化界面，轻松进行蓝图管理
- **智能识别**：只需添加包含蓝图文件（`.sbp` 和 `.sbpcfg`）的目录，程序会自动识别并渲染目录树结构
- **未来计划**：将支持从蓝图社区直接下载蓝图的功能

### 🎯 功能二：蓝图组配置

根据不同场景使用不同的蓝图组，告别所有蓝图混在一起的混乱！

**使用场景**：
- 大佬提供的蓝图包中，有的是用于建设基地的，有的是用于产线的
- 所有蓝图都塞进游戏会导致加载慢、产生卡顿
- 想找到想要的蓝图很麻烦，只能依赖搜索

**解决方案**：
- 创建自定义配置（如"基建配置"、"产线配置"等）
- 将蓝图源中的蓝图添加到对应的蓝图组配置
- 一键同步：点击同步即可将该配置的所有蓝图复制到游戏存档蓝图目录

**⚠️ 重要提示**：
- 同步操作会覆盖整个游戏蓝图库，包含您做的修改和自己创建的蓝图
- 如需保留现有蓝图，请先切换同步模式为"游戏蓝图目录 → 蓝图库"进行备份

**激活方式**：
1. 直接点击蓝图节点的激活按钮
2. 选中目录节点或选择多个蓝图节点，通过右键菜单激活节点

**蓝图信息查看**：
- 解析所有蓝图元数据
- 查看蓝图作者、配方等详细信息

### 🏷️ 功能三：标签视图

提供两种标签视图来查看您激活的蓝图：

- **标签视图**：标准视图
- **标签视图（水平）**：经过优化的 UI 界面

**标签逻辑**：
- 每个标签都支持"或"、"与"、"非"模式
- 支持批量添加标签来辅助筛选

### 🤖 功能四：与游戏的交互和联动

**核心功能**：在 SBM 中使用您激活的蓝图，实现自动化操作

- 配置自动化参数后，程序会自动执行蓝图使用流程
- 支持坐标标定，精确定位游戏界面元素
- 自动化执行：点击输入栏 → 输入蓝图名称 → 点击第一个蓝图

## 📦 安装

### Windows 端

目前仅支持 Windows 平台。

**安装包获取**：
- 从项目发布页面下载最新版本的安装包
- 运行安装程序，按照提示完成安装

## 🚀 快速开始

1. **首次启动**：程序会自动检测您的游戏存档位置
2. **添加蓝图源**：点击"添加源"按钮，选择包含蓝图文件的目录
3. **创建配置**：根据需要创建不同的蓝图组配置
4. **管理蓝图**：将蓝图添加到对应配置，使用标签进行分类
5. **同步到游戏**：选择配置后点击同步，蓝图将自动复制到游戏目录

- Node.js: `^28 || ^26 || ^24 || ^22 || ^20 || ^18`
