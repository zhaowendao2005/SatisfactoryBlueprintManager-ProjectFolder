## ⚠️ 踩的坑与经验总结

### 坑1：Quasar CSS路径解析问题
**问题**：`[plugin:vite:import-analysis] Failed to resolve import "src/css/Frontend/css/app.scss"`

**原因**：Quasar内部处理CSS路径时，会将配置的路径前面加上`src/css`前缀

**解决方案**：
1. 在quasar.config.ts中配置CSS路径为`Frontend/css/app.scss`
2. 添加`src/css`别名指向项目根目录（兼容Quasar内部生成的文件）
3. 或者使用Vite插件拦截并重写路径

**经验**：Quasar的文件结构敏感，修改初始结构后需要同步更新多个配置

### 坑2：Windows PowerShell环境变量设置
**问题**：`SKIP_LINT=true`在PowerShell中不生效

**原因**：PowerShell使用不同的环境变量设置语法

**解决方案**：使用`cross-env`包实现跨平台兼容
```json
"dev:no-lint": "cross-env SKIP_LINT=true node ../Script/run-with-logger.mjs --name dev-no-lint -- quasar dev"
```

**经验**：涉及环境变量的脚本应该使用cross-env确保跨平台兼容

### 坑3：Preload脚本路径重复
**问题**：`Unable to load preload script: D:\...\D:\...\electron-preload.cjs`

**原因**：路径解析时出现了重复的绝对路径

**解决方案**：检查electron-main.ts中的preload路径配置，确保使用相对路径或正确的path.resolve()

**经验**：Electron路径配置要谨慎，避免路径拼接错误

### 坑4：Element Plus类型定义问题
**问题**：TypeScript类型错误，Element Plus组件props类型不匹配

**原因**：Element Plus的类型定义与实际使用存在差异

**解决方案**：使用类型断言或忽略类型错误（不影响运行）

**经验**：第三方库的类型定义有时不完美，需要灵活处理

### 坑5：蓝图节点布局问题
**问题**：蓝图节点只显示元数据，没有标题

**原因**：组件模板中缺少标题显示逻辑

**解决方案**：添加标题显示，并重新设计为垂直布局（标题+元数据+摘要）

**经验**：组件布局设计要考虑数据结构的完整性

### 坑6：导航栏激活状态背景不显示
**问题**：蓝色背景被覆盖

**原因**：使用`z-index: -1`导致伪元素被父容器背景覆盖

**解决方案**：直接在`.active`上设置`background-color`，不使用伪元素

**经验**：CSS层级和定位要谨慎，避免使用负z-index
